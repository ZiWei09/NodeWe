# Documentation authority

The authoritative order for this repository is:

1. explicit user direction for the NodeWe product;
2. the checked-in NodeWe specifications under `spec/`;
3. the current source code, tests, and deployment templates;
4. public standards and the reviewed dependency inventory;
5. product and market documents, only for context and prioritization.

Product documents do not override the protocol, security, or release gates. When
code and prose differ, update the prose to match the tested implementation and
record the change in the release notes.
