# NodeWe implementation decision record

- Decision: implement the public NodeWe contracts from the checked-in
  specifications, public standards, and reviewed dependencies.
- Scope: the repository contains the NodeWe Control Plane, Node Runtime, CLI,
  SDK, deployment kit, tests, and operational records.
- Review gate: before merging or releasing an implementation, attach dependency
  inventory, license results, security scan, test results, and reviewer approval.
- Release evidence: record the toolchain, artifact checksums, verification
  commands, configuration assumptions, and known limitations in the release
  record.
